# Pocopie Games

A self-contained static landing page for Picture Puzzle. Production files live in `dist/`; no build or package installation is required.

Run `node preview.mjs` and open the printed address for local preview. The server binds only to the local machine. Stop it with Ctrl+C.

All download links open https://play.google.com/store/apps/details?id=com.pocopie.picturepuzzle. The original artwork is preserved in the parent project's `assets/` directory, with copies served in `dist/assets/`.

The site uses the bundled Nunito font, licensed under the SIL Open Font License; see `dist/assets/OFL.txt`. Hosting identity is stored in `.openai/hosting.json`.
